# polar_app

Настільна програма Polar (PyQt6) і вузол керування камерами `polar_control`.

Зараз є меню «Камери»:
- «Список» — камери з кнопками «Калібрування / Редагувати / Видалити» і «Додати»;
- форма камери (кнопки «Додати» і «Редагувати» у списку), перевірка зʼєднання, вимірювання затримки, живий кадр з кутами;
- «Управління» — стан звʼязку, кути, ручне керування, «Стоп», сервоприводи й телеметрія.
Калібрування — етап 3, решта меню — етап 8.

```bash
python3 -m pip install -e ../polar_core -e ../ros2_ws/src/pantilt_driver -e ".[gui]"
python3 -m polar_app --db polar.sqlite
```

Сервоприводи камер без демо керуються через ROS 2 — перед запуском `source /opt/ros/humble/setup.bash`
і `ros2_ws/install/setup.bash`.

**Демо вмикається окремо для кожної камери** — у формі камери або на екрані «Управління»:
- «Демо сервоприводів» — імітатор Raspberry Pi і ST3020 на сервері (логіка `pantilt_driver`), ROS 2 не потрібен;
- «Демо відео» — синтетична сцена замість відеопотоку, адреса потоку не потрібна.

Так можна, наприклад, перевіряти справжню вебкамеру з імітатором сервоприводів або справжні сервоприводи
з демо-відео.
