# polar_app

Настільна програма Polar (PyQt6) і вузол керування камерами `polar_control`.

Зараз є меню «Камери»:
- «Список» — камери з кнопками «Калібрування / Редагувати / Видалити» і «Додати»;
- «Редагування» — форма камери, перевірка зʼєднання, вимірювання затримки, живий кадр з кутами;
- «Управління» — стан звʼязку, кути, ручне керування, «Стоп», сервоприводи й телеметрія.
Калібрування — етап 3, решта меню — етап 8.

```bash
# Без Raspberry Pi і ROS: сервоприводи — імітатор з логікою pantilt_driver,
# відео — справжні потоки камер (у демо Камера 1 — USB-камера 0 цього компʼютера)
python3 -m pip install -e ../polar_core -e ../ros2_ws/src/pantilt_driver -e ".[gui]"
python3 -m polar_app --sim --demo

# З камерами через ROS 2 (спочатку source /opt/ros/humble/setup.bash і ros2_ws/install/setup.bash)
python3 -m polar_app --db polar.sqlite
```

`--demo` створює тимчасову базу з трьома камерами: Камера 1 — вебкамера компʼютера, Камери 2 і 3 —
приклади IP-камер (вкажіть свої адреси у формі). Без `--demo` використовується `--db`.
